# 小陈的编程复习室：网站源码

这是当前线上版本的静态网站源码，包含：

- 学习笔记与辅助学习资料
- 笔记图片资源
- C++ 在线编程入口
- 本地项目专区与项目模拟面试
- 选择题与简答题面试练习、错题回顾与章节完成标记
- 小林 Coding 图解与面试专区入口

## 启动网站（推荐，支持 CUDA 运行）

CUDA 服务已配置为登录后在后台自动运行，不需要打开终端。直接双击项目根目录中的 `启动学习网站.desktop` 或 `打开学习网站.html`，即可在浏览器打开：

```text
http://127.0.0.1:8765
```

此方式支持在笔记旁边编辑代码：普通 C++ 通过本机 `g++` 编译运行，CUDA 通过本机 `nvcc` 编译并在 NVIDIA GPU 上执行。服务只监听本机地址。

如果后台服务没有启动，也可以在终端临时执行：

```bash
./启动学习网站.sh
```

首次使用桌面入口时，如果系统询问是否信任，请选择“信任并启动”。

后台服务状态可以通过下面的命令查看：

```bash
systemctl --user status xiaochen-study.service
```

## 仅阅读模式

直接双击 `打开学习网站.html` 或 `dist/index.html` 时，如果本机服务已经运行，页面会自动切换到 `http://127.0.0.1:8765`，以便使用 ChatGPT 登录和代码运行；服务未启动时则保留离线阅读模式，仍可阅读全部笔记、做面试练习并回顾错题，但不能编译运行 C++ 或 CUDA。

如果修改了 `dist/note.md` 或 `dist/aux-notes.md`，请在项目根目录执行：

```bash
node build-note-data.mjs
```

这会更新供直接打开模式使用的 `dist/note-data.js`。

面试练习支持按专题和题型筛选：选择题在作答后自动判分；简答题需要先写下自己的回答，再对照参考要点自评“已经掌握”或“还需复习”。答错或自评未掌握的题会进入错题回顾。当前题库包含 60 道选择题和 24 道简答题。

## 添加本地项目

项目专区会读取本机目录，自动生成项目概览、简历素材和专属面试题。编辑根目录中的 `projects.json`，在 `projects` 数组中添加项目：

```json
{
  "version": 1,
  "projects": [
    {
      "id": "my-project",
      "name": "我的项目",
      "path": "/home/czq/项目目录",
      "summary": "项目解决的问题和主要功能。",
      "role": "我的职责",
      "period": "2026.01 - 至今",
      "tags": ["C++", "CUDA"],
      "highlights": ["可量化的项目成果"],
      "challenges": ["最有代表性的技术难点和解决方案"]
    }
  ]
}
```

双击 `启动学习网站.desktop` 时会自动扫描配置的目录并生成技术统计和项目面试题；打开“项目”页面时，本机服务也会再次刷新。扫描会跳过 `.git`、构建目录、依赖、数据集、模型以及名称疑似包含密钥或密码的文件。也可以手动更新：

```bash
node build-project-data.mjs
```

生成的 `dist/project-data.js` 仅包含项目概览、文件统计和面试问题，不包含完整源码。

项目材料采用通用的岗位定向生成流程：新项目第一次进入项目专区时，登录的 ChatGPT 会根据项目配置、目录扫描结果和脱敏源码摘录，面向 **C++ 开发 / CUDA 算子开发** 岗位同时生成“投递精简版”和“技术深挖版”。投递版只保留 1—2 句项目概述、核心技术栈和 4—6 条可直接用于简历的贡献；技术档案完整保留架构、C++ 工程、CUDA 算子、难点、结果、运行条件与待补量化证据。业务背景只做非领域面试官能够理解的简述，主体优先提炼源码可证明的 Modern C++、并发与资源生命周期、CUDA Kernel/算子、内存层次、同步、CPU-GPU 协同、Profiling 与性能取舍；网络和领域算法只作为数据规模、实时性及正确性约束。没有 CUDA 的项目不会凭空补写 CUDA，而会转为突出真实存在的 C++、系统编程和性能工程能力。生成结果保存在本机 `~/.config/xiaochen-study/project-resume-cache.json`；以后会同时比较源码指纹与生成规则版本，源码或岗位规则变化时自动重新生成，未变化时直接读取缓存。页面中的“重新分析源码”可强制刷新。

项目页提供两个互不冲突的切换维度：“内容深度”在“投递精简版”和“技术深挖版”之间切换；“简历内容来源”在“手写版”和“ChatGPT 自动版”之间切换。来源选择会同步保存到 `projects.json`，两个来源彼此独立：切到自动版不会删除手写内容，切回手写版会恢复原内容，AI 生成结果则继续保留在本机缓存中。也可以手工在 `resume` 中设置 `"mode": "manual"` 或 `"mode": "auto"`；未设置的新项目默认使用自动版，因此以后新增项目不会退化成只有几句话的基础描述。

手写版不会被源码更新自动改写。系统会在本机记录上次确认手写简历时的源码指纹；项目源码发生变化后，页面会显示“源码已变化，建议复核手写版”。检查内容后点击“已复核当前源码”即可清除提醒并建立新的复核基线。

技术深挖版按面试递进顺序组织为：项目全貌、系统架构与 CPU/GPU 数据流、C++ 工程、CUDA 算子、模块协同、可靠性与设计取舍、结果与复现、量化证据和源码索引。实现要点以可展开卡片显示，默认展开每章前两个重点；待实测数据和已经成立的工程结果分开呈现，避免把测试计划误当成项目成果。

项目连续面试提供三种运行方式：

- **使用 ChatGPT 登录（优先）**：在项目页点击“AI 面试官配置”，选择 `Continue with ChatGPT`。登录凭据仅保存到本机受保护文件，通过符合资格的 ChatGPT 套餐调用 Responses API。
- **OpenAI API Key（备用）**：未登录 ChatGPT、套餐授权不可用时，可继续使用本机 API Key。AI 会读取脱敏后的限量源码摘录，给出评分、证据缺口并连续追问。
- **本地连续追问**：使用网页内置题库与规则评价，不访问外部服务，适合无网络或 API 额度不可用时使用。

ChatGPT 登录记录保存在 `~/.config/xiaochen-study/chatgpt-auth.json`，文件权限为仅当前用户可读写；访问令牌不会进入网页源码、浏览器存储或项目文件。项目页可以保存并切换多个 ChatGPT 账号：“重新授权当前账号”沿用当前注册，“换一个 ChatGPT 账号”会创建独立账号注册；也可以退出当前账号或前往 ChatGPT 设置查看用量。

API Key 备用配置仍保存在 `~/.config/xiaochen-study/openai.env`，不会写入网页源码：

```text
OPENAI_API_KEY=你的 API Key
OPENAI_MODEL=gpt-6.1-sol
```

配置文件权限建议设为 `600`。修改后重新执行 `./安装后台服务.sh`。使用 ChatGPT 登录时，模型列表取自当前登录账号；使用 API Key 时，模型列表取自 API 账号。AI 模式会发送脱敏源码摘录和面试回答，敏感文件会被跳过，完整项目目录不会整体复制到网站目录。

项目页的“思考强度”会跟随当前模型自动变化，只显示该模型真正支持的档位。GPT-6.1 Sol 和 GPT-6 Astra 支持低、中、高、超高和最高；GPT-6 Sol、GPT-6 Luna、GPT-6.1 Terra 与 GPT-5.6 还会显示“关闭”。已选档位会保存在当前浏览器中，换成不支持该档位的模型时会自动回退到“中”。档位越高通常越适合深度源码分析，但延迟和用量也会增加。

## CUDA 环境自检

执行下面的命令，可以编译并运行一个最小 CUDA 内核：

```bash
node cuda-runner.mjs --self-test
```

CUDA 服务对单次编译和运行设置了超时、代码大小和输出大小限制。它会执行你在编辑器中提交的本机代码，因此只运行自己理解和信任的代码。

## 主要文件

- `dist/index.html`：页面结构
- `dist/styles.css`：界面样式
- `dist/app.js`：网站交互逻辑
- `dist/quiz-data.js`：面试练习题与知识卡片数据
- `dist/project-data.js`：自动生成的本地项目概览与项目面试题
- `dist/note.md`：学习总笔记
- `dist/note-data.js`：用于直接打开模式的笔记数据
- `dist/aux-notes.md`：辅助学习资料
- `dist/assets/note-images/`：笔记图片
- `cuda-runner.mjs`：本机 CUDA 编译、运行及静态网站服务
- `projects.json`：项目专区配置
- `build-project-data.mjs`：安全扫描本地项目并生成项目数据
- `启动学习网站.desktop`：图形化启动入口

小林 Coding 的专题内容通过原站页面加载，因此使用这些模块时需要联网。
